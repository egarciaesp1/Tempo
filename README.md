# Tienda de Música TEMPO
## Instrucciones de ejecución:
1. Clona este repositorio o descarga el código en un archivo zip.
2. Abre la carpeta del proyecto en Visual Studio Code.
3. Abre una terminal dentro del editor.
4. Escribe el comando "dotnet run" y dale a enter.
5. Sigue las instrucciones del menú interactivo en la consola.
